# Support

## Start here

- Read the [README](README.md) for installation, configuration, usage, and troubleshooting.
- Search existing [issues](https://github.com/bill9109/dsh-101/issues) and [pull requests](https://github.com/bill9109/dsh-101/pulls) before opening a duplicate.

## Where to ask

- Reproducible defect: open a bug report.
- Installation, configuration, or usage question: open a question.
- Focused product improvement: open a feature request.
- Security concern: follow [SECURITY.md](SECURITY.md) and report it privately.
- Code contribution: read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.

## Information to include

Provide the DSH snapshot and profile, plugin version, browser and OS versions, whether dsh-101 was installed into the `web` profile (it must not be), minimal reproduction steps, expected behavior, and sanitized output. Remove API keys, authorization headers, complete prompts or conversations, and unrelated workspace paths.
